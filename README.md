# 🧑‍💻 Single-Page CV

A simple, responsive **single-page CV** built using **HTML and CSS**.  
This project demonstrates semantic HTML structure, SEO optimization, Open Graph tags, and favicon integration — perfect for learning web fundamentals.

---

## 🚀 Features
- Semantic HTML layout (`<section>`, `<article>`, `<footer>`)
- SEO meta tags for better search visibility
- Open Graph (OG) tags for social media sharing
- Custom favicon for branding
- Clean, readable typography and spacing
- Beginner-friendly CSS styling
